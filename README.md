# rcc-audio

Pilot podcast feeds for Regeneration Calvary Chapel (Sandpoint, Idaho), teaching-only message audio.

- `ruth/feed.xml`: "Ruth (Audio) | Regeneration Calvary Chapel" (4 Wednesday-night messages through the Book of Ruth).
- MP3 files are attached to the GitHub Release `ruth-v1` (not stored in the repo).

Pilot hosting maintained by GoldWare (goldware.io) for RCC. The long-term home is a Subsplash podcast.
